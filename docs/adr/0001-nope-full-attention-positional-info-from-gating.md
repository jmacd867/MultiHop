# Positional encoding is per-variant: NoPE where KDA layers exist, RoPE otherwise

We're comparing three architectures (full-attention baseline, pure KDA linear-attention, 3:1 hybrid) on a synthetic multi-hop task designed to isolate hop-distance failure patterns. The obvious uniform default — RoPE on every full-attention layer in every variant, NoPE only on KDA layers — was considered, but we instead let full-attention layers go NoPE *wherever a KDA layer is present in the same model* (the pure-KDA and hybrid variants), relying on KDA's data-dependent gating to carry positional/order information through the residual stream. This keeps position-encoding responsibility concentrated in the mechanism actually under study rather than splitting it across RoPE and gating, which would confound the hop-distance comparison with two independent positional signals.

This rule cannot be applied uniformly: the pure full-attention baseline has no KDA layers at all, so NoPE there would leave the model with zero positional signal and structurally incapable of the task (fully permutation-invariant). The baseline therefore keeps RoPE on its full-attention layers as it normally would. The result is a per-variant rule, not a per-layer-type rule — a future reader will see full-attention layers with RoPE in one variant and without it in another and should not "fix" this into consistency; it's deliberate, tracking which variant has a mechanism available to carry position at all.
