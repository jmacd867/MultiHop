# Multi-Hop Linear-Attention Degradation Experiment

This project asks whether replacing full attention with a linear-attention mechanism (KDA, a delta-rule state-compression variant) changes how a model handles multi-hop retrieval: given a chain of entity-pair Facts (A→B, B→C, C→D, ...) buried in Distractors and Filler, can the model traverse from the Query's start entity to the chain's terminal entity, and does that ability degrade differently under state compression than under full attention? Three Variants sharing identical depth, width, and head count were compared: full attention, pure KDA, and a 3:1 hybrid (3 full-attention layers, 9 KDA layers, per ADR 0011's schedule). The task was deliberately hardened against shortcuts before this run — two earlier attempts (ADR 0015, ADR 0016, ADR 0018) found the generator solvable at 100% by copying a fixed token offset or exploiting fact-ordering artifacts, without the model ever reading the Query. This run's generator randomizes both gap length and fact order, and every reported number is checked against a traversal-free ceiling computed in advance (0.4803 mean over the valid surface), so a Variant's score can be judged as genuine traversal rather than a surface heuristic.

The result is clean: the 3:1 hybrid matches full attention (+1.28pp on the valid surface, 0.6 standard errors — no measurable difference), while pure KDA is measurably worse (−11.90pp, 5.4 SE). All three Variants genuinely traverse the chain — every one of the 16 valid grid cells clears its own traversal-free ceiling for every Variant, so none of this is shortcut execution. The three retained full-attention layers in the hybrid don't just narrow the gap between full attention and pure KDA, they recover essentially all of it: removing them costs 11.9 percentage points, and putting 3 of 12 back costs nothing measurable. Pure KDA's deficit is also flat across hop count (roughly 11–13pp at every depth from 2 to 5 hops) rather than widening with depth, which runs counter to the project's original motivating hypothesis that a compressed state should lose progressively more with each additional hop. That pattern reads more like a fixed capability tax from state compression than an accumulating traversal error.

What this experiment can't claim is at least as important as what it found. It cannot measure how performance degrades *along* the hop-count axis for any single Variant, because the traversal-free ceiling itself declines with hop count (0.60 at hop=2 down to 0.41 at hop=5), confounding capability with a moving bar — comparisons are only valid *within* a hop count, across Variants, not along the axis for one Variant. It does not establish that the hybrid *equals* the baseline, only that one seed per Variant shows no measurable difference; this is a null result, not a proof of equivalence. It says nothing about production KDA, since this is core-mechanism KDA without ShortConv, not Kimi Linear as deployed. And because none of the three Variants reaches saturation (all sit at 0.65–0.81 against a 1.0 ceiling), this comparison happens partway up each Variant's learning curve, not at its ceiling — a comparison at convergence could look different.
